## LiveActivities

**Overview**

LiveActivities is an iOS app that demonstrates using Live Activities and ActivityKit to display real-time updates via widgets and Dynamic Island.

**Features**

 - Start, update, and stop a Live Activity timer
 - Display Live Activity updates in widgets and Dynamic Island

**Setup**

1. Clone the repository: git clone https://github.com/YogashivasankarriSenthilkumar/LiveActivity.git
2. Open the project in Xcode.
3.Run the app on a physical iPhone (Live Activities don’t work in the simulator).

**Usage**

1. Tap Start Activity to begin the timer.
2. Tap Update Activity to extend the timer.
3.Tap Stop Activity to end it.

**Requirements**

- iOS 16.1+
- Xcode 14+
- Physical iPhone (required for Live Activities)
